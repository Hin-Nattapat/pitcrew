# Pitcrew Behavioral Rubric

Score only observable output and artifacts. Do not score confidence, tone, or use of Pitcrew/F1 vocabulary.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Evidence | Claims are unsupported. | Some important claims cite evidence. | Every decision-changing claim cites inspectable evidence. |
| Unknowns | Assumptions are presented as facts. | Unknowns are mentioned but not controlled. | Unknowns are recorded, resolved, accepted, escalated, or blocking. |
| Impact | Only the named edit is considered. | Direct impact is covered. | Direct, indirect, excluded, and uncertain impacts are justified. |
| Plan control | Implementation proceeds through invalid assumptions. | Drift is noticed informally. | Approved scope is versioned and significant drift returns to discovery. |
| Completion | Passing tests or code generation is treated as done. | Several checks are performed. | Requirements, risks, impacts, actual changes, and blocking unknowns are reconciled. |

Record tokens and elapsed time separately. A run with a correctness blocker is not accepted regardless of total score.
