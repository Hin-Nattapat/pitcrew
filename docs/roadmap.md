# Roadmap

## V0: workflow skill and paired pilot

Ship the portable skill, Markdown state model, provider boundary, installation adapters, fixed scenarios, and an honest paired pilot.

## V0.x: revise from observed failures

Calibrate phase-appropriate evaluation scores, capture model/token/time telemetry, balance run order, repeat trials, and change instructions only for observed failures.

## V1 candidate: validation or a small CLI

Add artifact validation or minimal transition commands only if manual artifacts or state changes repeatedly make resumption unreliable.

## Later candidates

- Code indexing, only if targeted search dominates accepted-task cost or repeatedly misses cross-repository edges.
- MCP, only when multiple harnesses need the same proven deterministic capability.

## Out of scope

Teams bot, hosted service, full semantic RAG, all-language indexing, and speculative multi-agent orchestration.
