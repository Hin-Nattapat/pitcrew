2. **Which artifact format is easiest for humans and agents to maintain: Markdown, YAML, or a hybrid?** Resolve when resumption failures, edit errors, and maintenance time are measured across representative tasks.
3. **What minimum number of paired tasks gives a useful signal within the available token budget?** Resolve through a preregistered sample-size or sequential stopping rule using observed outcome variance and cost.
4. **Which installation layout works consistently across current Claude Code and Codex releases?** Resolve when clean-machine tests install, discover, invoke, and update the same release in both harnesses.
5. **When does a change qualify as plan drift rather than an implementation detail?** Resolve when independently scored examples achieve an agreed classification rate and escaped material drift stays below the pilot threshold.
6. **Which provider identifiers remain stable across plugin namespaces and direct skill installations?** Resolve when an automated compatibility matrix records identifiers across supported installation modes and versions.
